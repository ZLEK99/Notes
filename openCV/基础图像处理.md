## 1、灰度化

灰度化就是**把彩色图变成灰度图**，核心是：把 R、G、B 三个通道合并成一个亮度值。

- 彩色图有 R、G、B 三个通道，数据量大、处理慢；
- 玻璃缺陷检测主要看**亮度变化、边缘、纹理**，颜色信息通常没用；
- 灰度图单通道，计算量小，后续二值化、边缘、形态学都基于灰度。

**一句话：降维、提速、突出亮度信息。****当颜色不重要、任务靠亮度/边缘/形状就能做、且要提速时，用灰度化；当颜色本身是关键特征时，不要灰度化。**

## 2、ROI裁剪

- 裁剪出**感兴趣区域**，只处理玻璃区域，提高速度和准确率。
- 图像里只有一部分区域是玻璃，其余是背景、夹具、边缘；全图处理浪费算力

一**句话：只算该算的地方，减少干扰和计算量**

## 3、中值滤波

- 相机噪声、光照不均会产生**椒盐噪声、孤立亮点/暗点**；
- 这些噪声会被误判成小缺陷；
- 中值滤波用邻域中值替代中心像素，能**去噪但保留边缘**，比均值滤波更适合缺陷检测。

**一句话：去噪，防止噪声被误判成缺陷。**中值滤波是**逐像素滑动窗口**

**均值滤波是“平均”，噪声和边缘都会被掺进结果，所以去噪不彻底、边缘会模糊**

```
核心思想：
1. 选择一个奇数尺寸的邻域窗口（最常用3×3、5×5），覆盖在目标像素上
2. 将窗口内所有像素的灰度值按大小排序，取出排在中间位置的数值
3. 用这个中值替换窗口中心原本的像素值，完成该点的滤波
```

## 4、椒盐噪声

- **椒**：黑色点（暗点，像素值接近 0）；
- **盐**：白色点（亮点，像素值接近 255）；
- 表现为图像上随机出现的**孤立黑点或白点**。

孤立亮点/暗点

- 周围像素正常，只有单个或几个像素异常亮/暗；
- 是椒盐噪声的典型表现。

为什么会产生？

| 原因       | 说明                            |
| :--------- | :------------------------------ |
| 传感器噪声 | CMOS/CCD 像素单元热噪声、暗电流 |
| 传输干扰   | 信号传输中受电磁干扰            |
| 光照不均   | 反光、灰尘、污渍                |
| 量化误差   | 模数转换误差                    |
| 坏点       | 传感器坏像素                    |
| 压缩/编码  | 图像压缩引入噪声                |

为什么影响缺陷检测

- 这些孤立点会被二值化、轮廓提取当成**小缺陷**；
- 造成**误检**；
- 所以要先滤波去噪。

## 5、二值化

**设定一个阈值 T，像素值大于 T 就变成 255（白），小于等于 T 就变成 0（黑）。**

| 对比       | 固定/参数化阈值 | Otsu       | 自适应阈值     |
| :--------- | :-------------- | :--------- | :------------- |
| 阈值来源   | 人为指定        | 全图自动算 | 每像素局部算   |
| 计算量     | 最小            | 小         | 大             |
| 光照稳定   | 好              | 好         | 好             |
| 光照不均   | 差              | 差         | 好             |
| 双峰直方图 | 看参数          | 好         | 一般           |
| 缺陷面积小 | 看参数          | 可能差     | 一般           |
| 参数调试   | 简单            | 不用调     | 邻域和 C 难调  |
| 适合场景   | 稳定产线        | 批量、双峰 | 光照不均、反光 |

## 7、灰度直方图

灰度直方图表示一张灰度图中，每个灰度值出现了多少次。

横轴：表示灰度值；纵轴：表示像素数量

```
作用：
1、帮助选择二值化阈值
2、判断光照是否稳定 可以看峰值，峰值变化大，光源可能有变化，曝光，相机参数等，固定阈值可能失效
3、判断图像质量 图像太暗，直方图集中在左侧；图像过曝，集中在右侧，太亮。
4、OTSU自动阈值和直方图关系：THRESH_OTSU分析灰度直方图。
                                例如发现两个峰：
                                背景峰
                                       缺陷峰
                                自动找到两个峰之间最低的位置：作为阈值。
```

## 8、Laplacian（拉普拉斯）边缘增强

Laplacian通过检测图像**灰度变化剧烈**的位置，**把边缘区域增强出来，让缺陷、轮廓更加明显。**

```
特点：
二阶导数
对细小变化敏感
容易受到噪声影响

适合：
细小划痕
微小缺陷增强
```

```
轮廓提取

```

## 11、形态学处理

**需要形态学处理的情况**

理想情况：

黑色：背景	白色：缺陷

```
希望：
    0000000000
    0000110000
    0000110000
    0000000000
```

但是实际因为：
    光照不均
    相机噪声
    灰尘
    玻璃纹理

```
可能变成：
    0000000000
    0000110100
    0000011000
    0000000010
```

出现：
    孤立白点
    缺陷断裂
    小孔洞
这时候就需要形态学处理。

### （1）腐蚀

作用：

> 让白色区域变小。

腐蚀可以：删除小噪点。

### （2）膨胀

作用：

> 让白色区域扩大。

膨胀用于：

- 连接断裂区域
- 填补小缺口

### （3）开运算和闭运算

开运算：腐蚀→膨胀  	闭运算：膨胀 → 腐蚀

原始: 大缺陷 + 小噪声  **开运算**后: 大缺陷  作用：去小白噪声。

**闭运算**：关闭小黑洞：膨胀 → 腐蚀	作用：填小黑洞、连接断裂。
