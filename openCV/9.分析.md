# 直方图

## 灰度直方图

- 灰度直方图表示一张灰度图中，每个灰度值出现了多少次。

  横轴：表示灰度值；纵轴：表示像素数量

  ```
  作用：
  1、帮助选择二值化阈值
  2、判断光照是否稳定 可以看峰值，峰值变化大，光源可能有变化，曝光，相机参数等，固定阈值可能失效
  3、判断图像质量 图像太暗，直方图集中在左侧；图像过曝，集中在右侧，太亮。
  4、OTSU自动阈值和直方图关系：THRESH_OTSU分析灰度直方图。
                                  例如发现两个峰：
                                  背景峰
                                         缺陷峰
                                  自动找到两个峰之间最低的位置：作为阈值。
  ```
