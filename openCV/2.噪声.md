# 椒盐噪声

- **椒**：黑色点（暗点，像素值接近 0）；
- **盐**：白色点（亮点，像素值接近 255）；
- 表现为图像上随机出现的**孤立黑点或白点**。

孤立亮点/暗点

- 周围像素正常，只有单个或几个像素异常亮/暗；

为什么会产生？

| 原因       | 说明                            |
| :--------- | :------------------------------ |
| 传感器噪声 | CMOS/CCD 像素单元热噪声、暗电流 |
| 传输干扰   | 信号传输中受电磁干扰            |
| 光照不均   | 反光、灰尘、污渍                |
| 量化误差   | 模数转换误差                    |
| 坏点       | 传感器坏像素                    |
| 压缩/编码  | 图像压缩引入噪声                |

为什么影响缺陷检测

- 这些孤立点会被二值化、轮廓提取当成**小缺陷**；
- 造成**误检**；
- 所以要先滤波去噪。
