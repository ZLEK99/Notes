## Laplacian

### （1）边缘增强

Laplacian通过检测图像**灰度变化剧烈**的位置，**把边缘区域增强出来，让缺陷、轮廓更加明显。**

```
特点：
二阶导数
对细小变化敏感
容易受到噪声影响

适合：
细小划痕
微小缺陷增强
```

### （2）边缘检测

**二值图，边缘是白点，背景是黑**

## Canny

提取清晰边缘

```
流程更复杂：
包括：
高斯滤波
梯度计算
非极大值抑制
双阈值连接

特点：
边缘更连续。

适合：
轮廓提取
尺寸测量
```

### 



| 方法      | 原理     | 优点     | 缺点     | 应用         |
| --------- | -------- | -------- | -------- | ------------ |
| Roberts   | 一阶梯度 | 快       | 抗噪差   | 简单检测     |
| Prewitt   | 一阶梯度 | 简单     | 精度一般 | 基础视觉     |
| Sobel     | 一阶梯度 | 稳定     | 边缘较粗 | 工业常用     |
| Laplacian | 二阶导   | 敏感     | 噪声大   | 细小缺陷     |
| Canny     | 多阶段   | 效果最好 | 复杂     | 高精度检测   |
| Edge Scan | 局部梯度 | 精确快速 | 依赖ROI  | **尺寸**测量 |
