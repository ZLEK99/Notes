为什么叫形态学处理？





**需要形态学处理的情况**

理想情况：

黑色：背景	白色：缺陷

```
希望：
    0000000000
    0000110000
    0000110000
    0000000000
```

但是实际因为：
    光照不均
    相机噪声
    灰尘
    玻璃纹理

```
可能变成：
    0000000000
    0000110100
    0000011000
    0000000010
```

出现：
    孤立白点
    缺陷断裂
    小孔洞
这时候就需要形态学处理。

# 腐蚀

作用：

> 让白色区域变小。

腐蚀可以：删除小噪点。

# 膨胀

作用：

> 让白色区域扩大。

膨胀用于：

- 连接断裂区域
- 填补小缺口

# 开运算

先腐蚀后膨胀 

原始: 大缺陷 + 小噪声  **开运算**后: 大缺陷  作用：去小白噪声。

# 闭运算

先膨胀 后腐蚀

作用：填小黑洞、连接断裂。
